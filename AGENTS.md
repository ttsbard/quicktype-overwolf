# Инструкции для агентов (AI Coding Agents)

## Документация Overwolf и MCP

- Проект использует **Overwolf Native**, не Electron. Для документации доступен официальный Overwolf Docs MCP; подключение и реальный поисковый запрос проверены 2026-10-23.
- Перед изменением Overwolf API искать сигнатуры в локальных `.d.ts`, если они установлены, затем использовать MCP для актуальной документации и примеров. Фильтр запросов: `facet_docusaurus_tag: ["docs-ow-native-current"]`.
- Инструмент сервера: `algolia_search_index_overwolf` (имя в клиенте может иметь MCP-префикс). Если он не подключён в текущую сессию, допускаются прямые JSON-RPC запросы к официальному endpoint; проверенный порядок и параметры описаны в [заметке о MCP](docs/development/overwolf-docs-mcp.md).
- MCP предоставляет поиск документации, а не управление работающим Overwolf или проверку фокуса в игре. Не выдавать успешный поиск за подтверждение поведения приложения.
- При недоступности MCP явно сообщить об этом и использовать официальную документацию/исходники Overwolf. Не угадывать API и не копировать инструкции настройки Claude Code как обязательные правила этого проекта.

## Правила работы с Git и версионированием

1. **Локальная разработка (Запрет автоматических пушей):**
   - Вся разработка ведётся **строго локально**.
   - **НЕ ПУШИТЬ каждый коммит** (`git push`) в удалённый репозиторий.
   - Коммиты создаются и остаются в локальной ветке.
   - Выполнять `git push` разрешено **исключительно по прямому и явному указанию пользователя**.

2. **Соглашения по коммитам:**
   - Использовать формат Conventional Commits:
     - `feat:` новая функциональность;
     - `fix:` исправление ошибок и багов;
     - `docs:` обновление документации;
     - `style:` правки форматирования или CSS;
     - `refactor:` рефакторинг кода без изменения поведения;
     - `chore:` вспомогательные задачи и поддержка.

3. **Контроль качества перед коммитом:**
   - Проверять валидность синтаксиса изменяемых файлов (JavaScript, JSON, HTML, CSS).
   - Убеждаться в сохранении целостности манифеста Overwolf (`quicktype-overlay/manifest.json`).

4. **Сборка и дистрибуция (Работа напрямую по исходникам):**
   - **НЕ запускать сборку архивов/пакетов** (`scripts/package-app.ps1`, zip в `dist/`) автоматически.
   - Расширение подключено в Overwolf наживую напрямую из папки `quicktype-overlay/` (unpacked extension), обновление выполняется вручную.
   - Сборку дистрибутива производить **исключительно по прямому запросу пользователя**.
