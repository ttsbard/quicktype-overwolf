# Разработка QuickType

## Структура

- `quicktype-overlay/` — манифест, HTML/JS/CSS и иконка unpacked-приложения.
- `scripts/` — вспомогательные утилиты; `tests/` — регрессионные проверки.
- `tools/qa-rest-server.py` — локальный приёмник текста для ручной проверки REST без TTS.
- `docs/` — документация; `.work/` — локальные игнорируемые материалы.
- `dist/` — архивы, исключённые из Git.

## Запуск и обновление

Нужен developer whitelist и Overwolf не ниже 0.250.0. В Development Options загрузите папку `quicktype-overlay/` через Load unpacked extension. После изменения исходников выполните ручной Reload. При запуске и клике по значку в хабе открывается поле ввода, доступное на рабочем столе и в игре. Окно настроек открывается кнопкой ⚙ из оверлея.

## Автоматические проверки

Из корня репозитория с Node.js 18 или новее:

```powershell
node --test tests/regressions.test.cjs
node --check quicktype-overlay/config.js
node --check quicktype-overlay/desktop.js
node --check quicktype-overlay/overlay.js
node --check scripts/patch-overwolf-gamelist.js
```

Тесты используют DOM/Overwolf/fetch-заглушки и локальный HTTP-сервер. Проверяются текстовые payload, GET, deadline, идентификаторы ответов, черновики, Escape, независимое сохранение полей, относительные ссылки и ресурсы HTML/манифеста. Это не замена проверке внутри CEF/игры. XML-валидация патчера использует системный Windows PowerShell.

## Ручной smoke-test

Для проверки без TTS-сервиса установите Python 3 и запустите `python tools/qa-rest-server.py` из корня репозитория. В QuickType укажите URL `http://127.0.0.1:10101`, метод POST, заголовки `{"Content-Type":"application/json"}` и шаблон `{"text":"{text}"}`, затем Save. После отправки через Speech test или из игры фраза должна появиться в консоли сервера; ответ — HTTP 200 с тем же текстом. Остановка сервера через Ctrl+C позволяет проверить ошибку отправки и сохранение черновика. Если порт занят TTSBard или другим сервером, сначала остановите его. Скрипт использует стандартную библиотеку Python и не входит в пакет расширения.

1. Настройте тестовый сервер, сохраните настройки и проверьте HTTP 2xx в desktop. Внешнему серверу нужен CORS.
2. Проверьте назначение хоткея в Overwolf: по умолчанию Ctrl+T; после обновления при необходимости переназначьте его вручную. В поддерживаемой игре вызовите оверлей, напечатайте черновик, скройте и откройте: текст должен сохраниться. Проверьте, что игра не выполняет своё действие на ту же комбинацию; при конфликте назначьте другой хоткей и повторите вызов/скрытие.
3. Enter: поле заблокировано до ответа; HTTP 2xx сразу очищает текст согласно настройке, а через 350 мс закрывает окно согласно настройке. Сообщение об успехе не отображается. HTTP 4xx/5xx сохраняет текст и показывает ошибку. Задержка более 15 секунд даёт timeout; не повторяйте запрос, не проверив результат на сервере.
4. Во время медленного запроса скройте и откройте окно, измените текст. Старый ответ не должен стереть новый ввод или закрыть окно.
5. Отключите closeOnEscape и проверьте Escape. Хоткей должен по-прежнему скрывать окно и возвращать управление игре.
6. Проверьте цвет/непрозрачность/подсказки до сохранения, затем Save и Reload.
7. Переместите/растяните окно, сохраните настройки desktop и перезагрузите приложение: геометрия должна сохраниться. Проверьте сброс 640×100, 100×100.
8. Для OBS выполните отдельный [тест записи](../research/03-obs-overlay-capture.md).
9. В desktop проверьте вкладки мышью и клавишами ←/→, Home/End. Измените параметр, переключите вкладку и сохраните: значение должно сохраниться, индикатор изменений — погаснуть. Верните изменённый параметр к сохранённому значению: кнопка сохранения должна отключиться.
10. При отсутствии сохранённой темы окно должно следовать режиму Windows и реагировать на его смену. Кнопкой ☀/☾ переключите светлую и тёмную темы и проверьте сохранение явного выбора после Reload. Отдельного видимого выбора «Системная» сейчас нет. Цвет игрового оверлея не должен зависеть от темы desktop.
11. Проверьте предпросмотр цвета/непрозрачности/подсказок и активный пресет. Сверните редактор запроса с неверными заголовками и сохраните из вкладки «Оверлей»: должна открыться вкладка «Подключение» и редактор заголовков. Успешный тест должен показывать свёрнутые подробности ответа, неуспешный — раскрытые.
12. Проверьте импорт JSON из файла, перетаскиванием и вставкой; до «Сохранить» рабочее подключение не меняется. Экспортируйте профиль, затем отмените выбор папки: новый файл появляться не должен. Проверьте буфер обмена и сообщения при ошибке записи.
13. После сброса окна введите несколько строк: высота должна расти после каждой строки и уменьшаться после очистки. Затем измените размер вручную: заданная геометрия должна сохраняться. Повторите на масштабах Windows 100% и 150%.
14. Проверьте шрифт и размер текста, светлый фон, закрытие ошибки и окна без потери черновика. Для смены языка ввода используйте обходной способ: скрыть окно → переключить раскладку → вызвать окно.
15. Проверьте английский интерфейс обоих окон, включая ошибки и статусы. Старый выбор русского языка не должен влиять на интерфейс. Кнопка темы находится в заголовке слева от «Свернуть», с интервалом 18 px; у метода и URL нет видимых подписей, но есть доступные имена для экранного диктора. Введённый текст и тело ответа сервера не изменяются.
16. При открытии настроек системные шрифты должны загружаться автоматически. При поддержке API разрешите доступ: семейства должны добавиться без дублей и смены текущего выбора. Выберите системный шрифт, проверьте предпросмотр, сохраните и выполните Reload. Если API недоступен или в доступе отказано, приложение должно сообщить причину и сохранить стандартный список. Если для первого разрешения требуется нажатие или предыдущий запрос завершился ошибкой, открытие списка шрифтов мышью или клавиатурой повторяет запрос. После успешной загрузки повторных запросов до Reload нет.

## Упаковка и Git

Разработка ведётся локально, Overwolf читает исходники напрямую. Локально `scripts/package-app.ps1` выполняется только по прямому запросу пользователя; автоматическая локальная упаковка и push запрещены. Патчер `scripts/patch-overwolf-gamelist.js` также запускается явно, с закрытым Overwolf. Коммиты — Conventional Commits после проверок.

CI для push и pull request в `master` создаёт `QuickType-<version>.zip` и `QuickType-<version>.opk` и сохраняет их в артефакте `QuickType-Release-ZIP-OPK` на 14 дней. При push тега `v<version>` оба файла прикрепляются к GitHub Release; версия тега должна совпадать с `manifest.json`.

ZIP содержит папку `quicktype-overlay/` для Load unpacked extension. OPK содержит файлы приложения и `manifest.json` в корне, согласно [формату Overwolf](https://dev.overwolf.com/ow-native/getting-started/release-your-app/). OPK не подписан Overwolf; создание пакета не гарантирует возможность установки в обычном клиенте. Скрипт упаковки автоматически вызывает `scripts/verify-packages.ps1`: проверяет структуру обоих архивов, обязательные ресурсы манифеста, совпадение наборов файлов и SHA-256 каждого файла с исходниками.
