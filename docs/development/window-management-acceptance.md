# Приёмка управления окнами (ROADMAP-004)

Реализация подготовлена 2026-10-23. Реальные игры и несколько физических мониторов агентом не проверены. Все пункты ниже ожидают ручного результата пользователя.

## Подготовка

1. В Overwolf вручную выполнить Reload для unpacked extension из `quicktype-overlay/`.
2. Зафиксировать версию Overwolf, игру, графический API, режим (borderless/fullscreen), разрешение, масштаб Windows, расположение мониторов и раскладки. Проверенный на машине файл клиента: 0.311.1.1; фактическую версию работающего процесса сверить в клиенте.
3. Открыть настройки → Overlay. По умолчанию Placement = Free position, отступ = 24. Режим и отступ применяются после Save; оформление по-прежнему имеет live preview.
4. При developer account при необходимости открыть `overwolf://api-tracing` для порядка оконных вызовов. Доступность страницы в живом клиенте ещё не проверена. Не передавать записи с REST payload, адресами приватных сервисов и авторизационными заголовками.

## Основной проход

| Проверка | Ожидается | Результат |
|---|---|---|
| Запуск и значок хаба; затем ⚙ | Ввод открывается; настройки доступны, повторных окон нет | Не проверено |
| Ctrl+T → печать → Ctrl+T → Ctrl+T | Черновик сохранён, фокус возвращён полю | Не проверено |
| 10 быстрых нажатий Ctrl+T; закрытие в момент появления | Последнее намерение определяет видимость, окно не возвращается само | Не проверено |
| Escape при включённой/выключенной Close on Escape | Соблюдается настройка; хоткей всегда доступен | Не проверено |
| Alt+Tab и открытие настроек сразу после вызова оверлея | Отложенные попытки не возвращают ввод из настроек | Не проверено |
| RU/EN в открытом поле, затем обычный набор | Сравнить с прежним поведением; указать потерю фокуса, если есть | Не проверено |
| Enter, ошибка сервиса, медленный ответ, новое открытие | Ошибки сохраняют текст; старый ответ не очищает новый ввод | Не проверено |
| Reset window | Размер 640×100 с учётом DPI и границ, по центру; авторазмер снова работает | Не проверено |
| Bottom center + отступ 40 → Save → несколько строк | Нижний отступ сохраняется, окно растёт вверх | Не проверено |
| Перетащить верхнюю панель закреплённого окна | Свободное размещение включается и сохраняется, другие настройки не теряются | Не проверено |
| Ручной resize, Reload | Размер сохраняется; автоматические resize до этого не фиксируются как ручные | Не проверено |
| Отключить второй монитор после сохранения позиции на нём | Окно возвращается в доступную область, настройки доступны | Не проверено |
| Монитор слева/сверху, DPI 100%/150%, смена разрешения | Нет двойного масштабирования, геометрия и элементы управления доступны | Не проверено |
| Fullscreen и borderless отдельно | Реальный ввод и возврат управления игре работают в поддерживаемом режиме | Не проверено |
| OOPO/trusted fullscreen | Отдельно записать доступность ввода; показ окна сам по себе не подтверждает работоспособность | Не проверено |

При ошибке записать точные действия, ожидаемое/фактическое поведение и оконные сообщения `[QuickType]` из DevTools. Из-за ограничений Native API уже отправленный вызов нельзя отменить; поздняя смена видимости исправляется следующим вызовом. Краткое мерцание/перехват ввода следует считать дефектом для разбора, а не успешным тестом.
