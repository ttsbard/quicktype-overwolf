# User documentation

QuickType is an in-game text input app for integrating with apps and services through APIs. Configure a compatible REST API or webhook to send messages, use bots or trigger automations without switching away from your game. A text-to-speech service is one possible integration; speech synthesis and audio routing are handled outside QuickType.

- [Overview and quick start](../../../README.md#english): setting up an integration, using the input window and known limitations.
- [Overwolf Developer Mode](developer-mode.md): developer access and loading QuickType.
- [Sharing connection settings](connection-json.md): importing and exporting JSON, with a TTSBard example.
