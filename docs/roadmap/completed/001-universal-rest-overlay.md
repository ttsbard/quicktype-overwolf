# ROADMAP-001: QuickType — Универсальный REST Overlay для Overwolf App Store

Этот документ фиксирует результат версии 0.3.0. Текущие настройки и ограничения описаны в [README](../../../README.md).

## Цель

Создать полноценное автономное приложение **QuickType** для платформы Overwolf, позволяющее игрокам и стримерам отправлять произвольные REST API запросы через внутриигровой эксклюзивный оверлей по горячей клавише, с удобным десктопным интерфейсом конфигурации.

## Ключевые возможности

1. **Главное окно настроек (Desktop Window):**
   - Конфигурация REST эндпоинта (URL, HTTP-метод GET/POST/PUT).
   - Шаблонизатор полезной нагрузки (JSON template с плейсхолдером `{text}`).
   - Настройка HTTP-заголовков.
   - Изменение геометрии перетаскиванием в игре и сброс положения/размера.
   - Тестирование сетевого соединения с отображением HTTP-статуса и времени ответа.
   - Переназначение горячей клавиши через настройки Overwolf.

2. **Игровой оверлей (In-Game Overlay):**
   - Вызов по настраиваемому хоткею (`Ctrl+Shift+F9`).
   - Мгновенный захват клавиатурного ввода в Direct3D/Vulkan играх через Exclusive Mode.
   - Автоматический перевод фокуса в поле ввода.
   - Отправка по **Enter** с ожиданием HTTP 2xx и закрытием через 350 мс при включённой настройке; при ошибке текст сохраняется.
   - Скрытие по **Escape** при включённой настройке с сохранением черновика.

3. **Подготовка к Overwolf App Store:**
   - Подготовка к проверке гайдлайнов Overwolf: ow-native манифест, Desktop и In-Game окна, иконки; соответствие подтверждается отдельным ревью.
   - Упаковка в дистрибутивный архив (`QuickType-0.3.0.zip`).

## Этапы реализации

- [x] **Этап 1: Валидация механики ввода** (исследование MixMode, отключение SmartMixMode, подтверждение Exclusive Mode).
- [x] **Этап 2: Двухоконный прототип QuickType** (Desktop окно настроек + In-Game оверлей + фоновый контроллер запросов).
- [x] **Этап 3: Полировка UI/UX** (валидация JSON, Twitch тёмная тема, обход CORS через overwolf.web, детальная диагностика сети).
- [x] **Этап 4: Релизная альфа-упаковка и документация** (дистрибутивный архив `QuickType-0.3.0.zip`, LICENSE, CHANGELOG, документация).
- [x] **Этап 5: Подготовка дистрибутива и архитектуры** (чистый ow-native манифест с `desktop_only`, кастомный titlebar окна настроек, 8-точечный ресайз оверлея, интеграция с TTSBard по умолчанию).

## Outcome

Дорожная карта полностью реализована и закрыта с выпуском релиза **QuickType 0.3.0**:

1. **Архитектура двухоконного оверлея:**
   - **Главное окно настроек (`desktop.html`):** собственный нативный заголовок окна с кнопками управления (`_`, `×`) и перетаскиванием `dragMove` (без лишних оверлейных контролов Overwolf), преднастройка под локальный сервис TTSBard из коробки, полная настройка произвольных REST/Webhook параметров, шаблонизатор полезной нагрузки, выбор цвета с контрастным пикером и тестовая панель отправки с кнопкой скрытия результатов.
   - **Внутриигровой оверлей (`overlay.html`):** эксклюзивный мгновенный захват фокуса клавиатуры, многострочный ввод (`Enter` для отправки, `Shift+Enter` для переноса), свободное перемещение и ресайз за любой из 8 краёв или углов окна, лаконичный тихий вывод ошибок без мерцания рамок.
   - **Фоновый контроллер (`background.html`):** глобальный хоткей (`Ctrl+Shift+F9`), безопасный двухэтапный цикл отправки запросов с подтверждением HTTP 200, 15-секундный таймаут, защита от дублей и сохранение черновиков при скрытии.

2. **Готовность к дистрибуции:**
   - Автоматизирован скрипт упаковки [`scripts/package-app.ps1`](../../../scripts/package-app.ps1), собран релизный архив `dist/QuickType-0.3.0.zip`.
   - Подготовлена полная документация: гайд по Developer Mode, исследование OBS Game Capture, архитектурный анализ MixMode, changelog и README.
   - Тестовое покрытие: 32 регрессионных теста (`tests/regressions.test.cjs`) подтверждают корректность шаблонизатора, сетевого контроллера, управления окнами и совместимости.
