# ROADMAP-003: Обмен подключениями через JSON

## Цель

Передавать настройки подключения другим пользователям и быстро загружать их.

## Формат и поведение

Четыре поля: `apiUrl`, `httpMethod`, `headers`, `payloadTemplate`. Заголовки — объект строк, тело — JSON-объект, массив или строка. Обязателен URL; отсутствующие остальные поля получают стандартные значения TTSBard. Неизвестные поля отклоняются с объяснением.

Импорт из файла UTF-8 или вставленного JSON, до 1 МБ. После полной проверки заменяется только подключение в форме; ошибки не меняют форму. Применение в игре — кнопкой «Сохранить». Экспорт текущей формы в `quicktype-connection.json`, включая несохранённые изменения и ключи доступа. Оформление, поведение и геометрия оверлея исключены.
