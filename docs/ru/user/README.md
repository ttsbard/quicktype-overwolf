# Пользовательская документация

QuickType — внутриигровое приложение для ввода текста и интеграции с приложениями и сервисами через API. Настройте совместимый REST API или webhook, чтобы отправлять сообщения, использовать ботов или запускать автоматизации без переключения из игры. Сервис синтеза речи — один из вариантов интеграции; озвучивание и передача звука настраиваются вне QuickType.

- [Описание и быстрый старт](../../../README.md#русский) — настройка интеграции, использование поля ввода и известные ограничения.
- [Получение Developer Mode в Overwolf](developer-mode.md) — доступ разработчика и загрузка QuickType.
- [Обмен настройками подключения](connection-json.md) — импорт и экспорт JSON, готовый пример TTSBard.
