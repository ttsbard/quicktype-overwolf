# Обмен настройками подключения

На вкладке **Connection** («Подключение») можно экспортировать текущие параметры и передать JSON другому пользователю. Оформление, поведение и положение оверлея в файл не входят.

## Экспорт

Нажмите **Export JSON** («Экспорт JSON»): приложение подготовит файл `quicktype-connection.json` из текущих значений формы, в том числе несохранённых. Заголовки экспортируются полностью, включая ключи доступа.

В зависимости от доступных API откроется диалог сохранения файла или выбора папки. Если диалоги недоступны, Overwolf использует доступную папку рабочего стола или документов. Отмена открытого диалога не записывает файл. JSON также копируется в буфер обмена; если копирование не удалось, приложение откроет поле импорта с подготовленным JSON для ручного копирования.

## Импорт

1. Нажмите **Import JSON** («Импорт JSON»).
2. Выберите файл UTF-8 `.json`, перетащите его на область выбора файла или вставьте JSON в текстовое поле.
3. Нажмите **Apply** («Применить»). При ошибке параметры подключения останутся прежними.
4. Проверьте адрес и при необходимости нажмите **Send** («Отправить») в разделе **Speech test** («Проверка озвучивания»).
5. Нажмите **Save** («Сохранить»), чтобы использовать подключение в игре.

Пример подключения к TTSBard ([JSON-файл для импорта](../../examples/ttsbard-connection.json)):

```json
{
  "apiUrl": "http://127.0.0.1:10101/v1/speech",
  "httpMethod": "POST",
  "headers": {
    "Content-Type": "application/json"
  },
  "payloadTemplate": {
    "text": "{text}"
  }
}
```

Обязателен `apiUrl` с `http://` или `https://`. Если другие поля пропущены, используются POST, заголовок `Content-Type: application/json` и тело `{"text":"{text}"}`. Поддерживаются методы GET, POST и PUT. Неизвестные поля отклоняются, чтобы опечатка не меняла смысл подключения незаметно.

`headers` — JSON-объект со строковыми значениями. `payloadTemplate` — объект, массив или строка для произвольного тела запроса. `{text}` заменяется текстом из оверлея. Для GET тело не отправляется; `{text}` можно указать в URL, иначе текст добавится в параметр `text`.

Максимальный размер файла или вставленного JSON — 1 МБ. Импорт полностью заменяет четыре параметра подключения в форме, не меняя остальные настройки.
